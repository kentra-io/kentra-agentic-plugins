# kentra-agentic-plugins — Agent Instructions

This repo is a **catalog only**. It holds no skills, agents, or code of its own —
just [`.claude-plugin/marketplace.json`](./.claude-plugin/marketplace.json), which
lists each kentra primitive plugin by its own repository.

- To add a primitive: append an entry to `marketplace.json` pointing at its repo.
- The primitives themselves stay neutral/unbranded (MIT, own repos); the `kentra-`
  brand lives here, in the catalog. See [README.md](./README.md) for the rationale.
